# MORI! memento

Ceci est un site web de fan inspiré de l'album [MORI! memento](https://open.spotify.com/intl-fr/album/7aWYd2PpykDRiNLK8HJ9Dv) de [TKKF](https://open.spotify.com/intl-fr/artist/2UkuW3yyd5zeKnx4hVz6No)

![MORI! memento](/public/cover.jpg)

## Installation et lancement
Le projet est réalisé avec `Vue.js 3` et `Sass`
Pour installer le projet localement, utilisez ces lignes dans votre terminal
```bash
git clone https://github.com/spiderLambo/MORI-memento.git
cd MORI-memento
npm install
npm run dev
```
